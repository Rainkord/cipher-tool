# Шифровальщик

Консольный скрипт для шифрования и дешифрования текста с использованием классических методов.

## Возможности

- **5 методов шифрования:**
  1. Атбаш — зеркальная подстановка букв
  2. Шифр Тритемия — сдвиг растёт с каждой позицией
  3. Шифр Белазо — сдвиг по повторяющемуся ключу
  4. Шифр Виженера с самоключом — ключ + сам текст
  5. Шифр Виженера с ключом-шифртекстом — ключ + шифртекст

- **Алфавит:** русский, 32 буквы (без Ё)
- **Формат вывода:** группы по 5 символов
- **Спецсимволы:** точка → ТЧК, запятая → ЗПТ, тире → ТИРЕ

## Использование

```bash
./cipher.sh
```

Скрипт интерактивный — просто следуйте подсказкам меню.

## Пример

```
На вход:
Старого воробья на мякине не проведёшь.
Зашифрованный:
СТАРО ГОВОР ОБЬЯН АМЯКИ НЕНЕП РОВЕД ЕШЬТЧ К
ОНЯПС ЬСЭСП СЮГАТ ЯУАХЧ ТЪТЪР ПСЭЪЫ ЪЗГНИ Х
```

## Требования

- Bash 4.0+
